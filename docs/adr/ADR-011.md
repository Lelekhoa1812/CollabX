# ADR-011: RBAC/ABAC With PostgreSQL RLS

Status: Accepted
Context: Project data has tenant, role, authority, classification and consent constraints.
Decision: Enforce application RBAC/ABAC and PostgreSQL RLS defense in depth.
Alternatives: Frontend-only visibility; database-only policy.
Consequences: Every command/query needs explicit permission and policy tests.
Security/Privacy: Missing attributes deny; no implicit platform-admin bypass.
Migration: Policy matrix evolves through reviewed fixtures.
Rollback: Feature flags can disable high-risk commands.
Owner: Security lead
Approval: Security advisor
