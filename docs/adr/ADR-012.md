# ADR-012: Australian Regional Deployment Cell

Status: Proposed
Context: Data residency and client trust require regionally repeatable architecture.
Decision: Use an Australian deployment cell initially with repeatable Bicep environments.
Alternatives: Single global region; per-client bespoke environments.
Consequences: Regional service availability must be verified before production.
Security/Privacy: Production never shares data, identities, secrets or network with non-production.
Migration: Add regions by reusing modules and environment composition.
Rollback: Keep recovery environment separated from production.
Owner: Platform lead
Approval: Data residency decision pending
