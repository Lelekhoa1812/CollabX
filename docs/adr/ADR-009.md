# ADR-009: Process Modelling Editors

Status: Accepted
Context: Consultants need conceptual maps and formal process models.
Decision: Use React Flow for conceptual graphs and BPMN.io for formal BPMN flows.
Alternatives: Proprietary canvas only; BPMN everywhere.
Consequences: The domain model stores structured process facts separately from editor layout.
Security/Privacy: Diagrams are classified project artefacts.
Migration: Export adapters can convert approved models to standard formats.
Rollback: Preserve process data while disabling editor-specific features.
Owner: Frontend lead
Approval: Product owner
