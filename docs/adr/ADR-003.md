# ADR-003: Application Model Gateway Over Foundry OpenAI

Status: Accepted
Context: AI output must be typed, policy-bound, observed and never authoritative state.
Decision: Route Microsoft Foundry `/openai/v1` calls through an application-owned Model Gateway.
Alternatives: Direct SDK calls from features; managed Agent Service for all capabilities.
Consequences: Adds a shared policy/cost/evaluation layer before feature agents.
Security/Privacy: Prompts, responses and traces are redacted before export; managed identity preferred.
Migration: Selective managed agents require a new ADR or update.
Rollback: Feature ports can fall back to deterministic insufficient-information responses.
Owner: AI lead
Approval: Solution architect
