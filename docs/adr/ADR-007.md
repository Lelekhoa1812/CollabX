# ADR-007: Transcript-First Audio Retention

Status: Proposed
Context: Voice sessions improve discovery but audio is sensitive and storage-heavy.
Decision: Default to transcript-first retention; raw recording is opt-in with short policy retention.
Alternatives: Always store recordings; never store recordings.
Consequences: Consent, correction and deletion workflows must be explicit.
Security/Privacy: No emotion, accent or personality inference.
Migration: Tenant policy classes define retention before pilot data.
Rollback: Disable recording while preserving text session capability.
Owner: Privacy advisor
Approval: Product owner pending
