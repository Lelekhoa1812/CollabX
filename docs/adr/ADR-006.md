# ADR-006: Entra External ID And Contribution Links

Status: Accepted
Context: Clients need authenticated access while limited survey participation may be link-based.
Decision: Use Entra ID for workforce, Entra External ID for clients, and scoped expiring contribution links for limited participation.
Alternatives: Email-only login; shared client accounts; unrestricted public forms.
Consequences: Stakeholder identity confidence remains separate from business authority.
Security/Privacy: Link tokens are hashed, scoped, expiring, revocable and non-approving.
Migration: Contribution links can later bind to external identities.
Rollback: Disable public grants without disabling authenticated portals.
Owner: Identity lead
Approval: Security advisor
