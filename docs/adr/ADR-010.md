# ADR-010: JSON Schema Event Registry

Status: Accepted
Context: Events must survive at-least-once delivery and independent consumers.
Decision: Store event schemas in source control with compatibility checks and major-version rules.
Alternatives: Ad hoc Python models only; broker-managed schema registry only.
Consequences: Producers and consumers must tolerate additive optional fields.
Security/Privacy: Events carry tenant/project/classification and never raw secrets.
Migration: Breaking changes require a new major schema and dual-read period.
Rollback: Replay from immutable outbox after consumer repair.
Owner: Platform lead
Approval: Principal architect
