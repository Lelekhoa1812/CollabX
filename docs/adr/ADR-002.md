# ADR-002: Temporal Durable Workflow Runtime

Status: Proposed
Context: Discovery, ingestion, export and AI work require durable waits, retries and human decisions.
Decision: Use Temporal Python SDK with deterministic workflow code and all side effects in activities.
Alternatives: Celery/RQ; custom database job runner; Azure Durable Functions.
Consequences: Requires replay tests, workflow versioning and operational runbooks.
Security/Privacy: Payload codec and retention policy must match tenant classification.
Migration: Temporal Cloud is preferred where procurement and data policy permit.
Rollback: Keep activity contracts portable so another durable runtime can be evaluated.
Owner: Platform lead
Approval: Procurement/data policy pending
