# ADR-005: Azure AI Search For Hybrid Retrieval

Status: Accepted
Context: The system needs full-text, vector, ACL-aware and semantic retrieval at scale.
Decision: Use Azure AI Search as a rebuildable projection, merged with RRF and optional semantic rerank.
Alternatives: PostgreSQL pgvector-only; third-party vector database.
Consequences: Index rebuild and ACL propagation are mandatory.
Security/Privacy: Strictest source classification propagates to every chunk and index document.
Migration: PostgreSQL remains authoritative, so indexes can be recreated.
Rollback: Disable semantic ranking and use deterministic source queries during outage.
Owner: AI/search lead
Approval: Solution architect
