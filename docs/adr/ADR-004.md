# ADR-004: PostgreSQL As Source Of Truth

Status: Accepted
Context: Project truth requires relational constraints, JSON flexibility, versioning and transactions.
Decision: Use PostgreSQL as authoritative state; graph/search projections remain rebuildable.
Alternatives: Primary graph database; document database.
Consequences: Graph-like queries must be carefully indexed and may later justify projections.
Security/Privacy: PostgreSQL RLS is a defense-in-depth requirement.
Migration: Add graph projection only after measured need.
Rollback: Rebuild projections from PostgreSQL.
Owner: Backend lead
Approval: Principal architect
