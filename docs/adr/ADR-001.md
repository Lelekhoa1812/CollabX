# ADR-001: Modular Monolith Plus Independent Workers

Status: Accepted
Context: The MVP needs strong domain consistency, fast iteration and later service extraction options.
Decision: Use a FastAPI modular monolith for synchronous APIs with separately deployable Temporal workers.
Alternatives: Microservices from day one; single process web/API/worker.
Consequences: Clear module boundaries and events are required to prevent hidden coupling.
Security/Privacy: Centralized policy enforcement and RLS reduce cross-service authorization drift.
Migration: Split modules only after measured scale or ownership pressure.
Rollback: Keep module APIs internal until extraction is approved.
Owner: Principal architect
Approval: Product owner and solution architect
