# ADR-013: Dependency Baseline

Status: Accepted
Context: TASK-002 requires locked framework/runtime choices from stable supported releases.
Decision: Use Python 3.13, FastAPI 0.124.2, Pydantic 2.13.4, SQLAlchemy 2.0.45, Alembic 1.17.2, PostgreSQL 17, React 19.2, Vite 7, TypeScript 5.9, Tailwind 4, Vitest 4 and Playwright 1.57.
Alternatives: Earlier LTS-only frontend stack; Django backend; Node backend.
Consequences: Lockfiles are mandatory and dependency drift is a CI failure.
Security/Privacy: Dependency updates require SCA, tests and reviewed changelog impact.
Migration: Group low-risk updates; major upgrades require ADR update.
Rollback: Revert lockfile and manifest together.
Owner: Platform lead
Approval: Principal architect
