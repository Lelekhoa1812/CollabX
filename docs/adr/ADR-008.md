# ADR-008: Isolated Python Artefact Rendering

Status: Accepted
Context: BRD/SRS/handover artefacts need controlled DOCX/PDF/XLSX rendering and QA.
Decision: Use isolated Python rendering with LibreOffice/PDF conversion and visual QA.
Alternatives: Browser-only export; SaaS document renderer.
Consequences: Renderer workers need sandboxing, resource limits and reproducible templates.
Security/Privacy: Exports inherit source classification and publication approvals.
Migration: Template DSL can gain additional render backends later.
Rollback: Disable publication while preserving draft artefacts.
Owner: Export lead
Approval: Solution architect
