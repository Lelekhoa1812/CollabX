# Change Control

Changes that alter scope, data ownership, security posture, AI behavior, provider commitments, lifecycle gates, generated artefact meaning, contracts, migrations or release evidence require:

1. Requirement IDs and affected acceptance criteria.
2. ADR impact assessment or a new ADR when architecture changes.
3. Security, privacy, responsible AI and data-residency review.
4. Migration, rollback and release evidence plan.
5. Product owner and solution architect approval for material changes.

AI-generated proposals are never accepted as authoritative changes until reviewed and committed by an authenticated human command.
